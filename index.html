PintRust

A lightweight, native Pinterest client for GNOME.

Built with Rust, GTK4, libadwaita and WebKitGTK 6.0. Persistent login, native navigation, light/dark theme sync, and OAuth popups that stay in the app.

Download Source code

Install with Flatpak

flatpak install --user https://lurima12.github.io/pintrust/com.lurim412.PintRust.flatpakref
flatpak run com.lurim412.PintRust

Run the AppImage

chmod +x PintRust-x86_64.AppImage
./PintRust-x86_64.AppImage

Requirements

The Flatpak needs org.gnome.Platform//51. The AppImage needs bwrap and a /var/tmp that allows executing files.
